# Career Counselling Pages

This folder contains the DreamGlobal career counselling page flow.

- `CareerCounselling.tsx` is the route page used by `/career-counselling`.
- `src/components/CareerCounselling.tsx` is the main career counselling content section.
- `src/components/Reveal.tsx` provides the small reveal animation wrapper.
- `src/lib/site-data.ts` contains the benefits and roadmap copy used by the section.

Keep career counselling, psychometric assessment, and student guidance page work here. The main landing page stays directly in `src/pages/Landing.tsx`, and higher-studies pages stay in `src/pages/higher-studies`.
