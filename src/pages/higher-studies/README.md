# Higher Studies Pages

This folder contains the earlier DreamGlobal higher-studies and abroad-education pages.

- `Index.tsx` is the higher-studies homepage.
- `Countries.tsx` and `CountryPage.tsx` handle destination pages.
- `Blogs.tsx` and `BlogPost.tsx` handle blog content.
- `CallbackLanding.tsx`, `MBBS.tsx`, `MBBSGuide.tsx`, `FAQs.tsx`, and `SuccessLetters.tsx` support the existing study-abroad flow.

Keep older higher-studies, country, admission, MBBS, blog, FAQ, and success-letter page work here.
